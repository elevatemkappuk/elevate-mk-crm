# Manrope

Self-hosted variable WOFF2 font, weights 400–700. Latin is preloaded; Latin Extended
loads only when required by text. `src/styles/_fonts.scss` declares both subsets
with `font-display: swap`. No external font service is contacted at runtime.

Retrieved from Google Fonts (Manrope v20), 2026-09-08:

- Latin: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Latin Extended: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggmxSuXd.woff2
- Licence: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt

The original SIL Open Font License is included as `OFL.txt`.
